# shoots/<品牌ID>.json — 每個品牌、每樣商品自己的拍法(精簡引擎 v2.31 起會讀)

格式:`{ "brand": { "s": [拍法句…] }, "products": { "商品名(跟後台一模一樣)": { "s": [拍法句…] } } }`
- 商品名對到就用商品的;對不到才用 brand 的;都沒有就用通用品類拍法。
- 每一句都要做到 MOZ 五件事:一個具體又意想不到的主意、背景是有決定的顏色(中間調,不是米白淺灰)、
  一道有方向的硬光且影子看得到、主角大、真實地點與材質。英文、一句一個完整畫面。
- 新品牌進駐 → 照這個格式補一個檔(地端每日工作會自動補缺的)。


## genre：品牌的「頂級拍攝類型」（2026-11-20 RA）
每個品牌一個：它那個世界裡最好看的那一類照片（MOZ＝北歐生活型錄、BCS＝電影劇照、旺味＝日本美食雜誌拍台灣小吃）。
格式：`"genre": {"zh": "中文給老闆看", "en": "英文給生圖用：類型 + 那一類的光、場景、氣質"}`。
美術指導照這一類攝影師的眼光拍；質感要真，不能太爛也不能太完美（太乾淨、像 CGI 也不行）。
新品牌進駐：每日補拍法工作要先寫 genre，再寫拍法句子；拍法句子也要符合這個類型。
