隱私政策

📌 Brand OS 是芮比廣告行銷（RABY D&C）的內部專用廣告管理系統，僅供授權員工及合作客戶使用，不對一般大眾開放。

一、系統概述

Brand OS（以下簡稱「本系統」）由創捷國際貿易股份有限公司（統一編號：90497380）開發及營運，部署於 https://ai.raby.com.tw。本系統整合 Meta Marketing API、Google Ads API、Google Drive 及多項 AI 服務，協助廣告代理商管理客戶品牌的廣告投放數據與素材製作。

二、資料收集範圍

本系統僅收集下列必要資訊：

  • 登入驗證資訊：Google 帳號電子郵件地址，用於身份驗證（白名單制度）
  • 廣告績效數據：透過 Meta Marketing API 存取的廣告花費、曝光、點擊、轉換等聚合數據，屬於廣告帳戶業務資訊，非個人消費者資料
  • 素材檔案：存放於授權使用者自行提供的 Google Drive 資料夾中的產品圖片及影片
  • 系統操作記錄：Cloudflare Workers 基礎日誌，用於系統維護與除錯

三、Meta Marketing API 資料使用說明

⚠️ 本系統透過 Meta Marketing API 存取的所有廣告數據，嚴格遵守 Meta Platform Terms 及 Developer Data Use Policy。

本系統存取 Meta Marketing API 的目的與範圍：

  • ads_read 讀取廣告帳戶績效數據（花費、ROAS、頻率、CTR、CPM 等）用於廣告成效分析
  • business_management 管理芮比廣告行銷代理之客戶廣告帳戶存取權限

本系統明確聲明不會將 Meta 廣告數據用於以下用途：

  • 轉售或提供給任何第三方
  • 用於芮比廣告行銷代理服務範圍以外的廣告投放
  • 建立消費者個人檔案或行為追蹤
  • 與其他平台的個人識別資訊（PII）合併

四、資料儲存與安全

  • 廣告數據透過 Cloudflare Workers 即時中轉處理，不在本系統伺服器長期儲存原始數據
  • 所有 API 金鑰及存取權杖均以加密方式儲存於 Cloudflare Workers 環境變數中
  • 系統採用 Google OAuth 2.0 進行身份驗證，並設有白名單機制限制存取人員
  • GitHub Pages 靜態前端，不含資料庫，不儲存使用者個人資料

五、資料分享對象

本系統使用以下第三方服務，各服務的資料處理依其各自隱私政策規範：

  • Meta Platforms Inc. — Marketing API（廣告數據來源）
  • Google LLC — Google OAuth、Google Drive API、Google Ads API
  • Anthropic PBC — Claude API（文案生成）
  • fal.ai — AI 圖像及影片生成服務
  • Cloudflare Inc. — Workers 運算及 CDN 服務
  • LINE Corporation — 廣告異常通知推送

本系統不會在上述以外的第三方分享任何資料。

六、Cookie 及追蹤技術

本系統使用 localStorage 儲存使用者登入狀態及介面偏好設定（如選擇的品牌、帳號設定），不使用第三方追蹤 Cookie，不安裝 Meta Pixel 或 Google Analytics 等分析工具。

七、使用者權利

授權使用者對其個人資料享有以下權利：

  • 存取權：可向系統管理員要求查閱系統中與其相關的資料
  • 刪除權：可要求移除帳號存取權限及相關記錄
  • 撤回授權：可隨時透過 Google 帳號設定撤回 OAuth 授權

如需行使上述權利，請聯絡：admin@raby.com.tw

八、適用對象

本隱私政策適用於所有存取 ai.raby.com.tw 的授權使用者，包含芮比廣告行銷員工及經授權的客戶代表（如 misa@owohad.com 等合作夥伴）。

九、政策更新

本政策如有重大修訂，將透過 LINE 通知或電子郵件通知所有授權使用者。繼續使用本系統即表示同意更新後的隱私政策。
